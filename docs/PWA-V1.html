Fluye PWA — primera versión

Instalable desde Chrome/Edge y con pantalla pública sin conexión. No es un .exe ni incluye MySQL. El código se comparte en GitHub; su ejecución sigue requiriendo servidor y MySQL. La instalación móvil requiere una dirección HTTPS accesible.

Probar en PowerShell

npm.cmd run build
$env:HOST="127.0.0.1"
$env:PORT="4321"
npm.cmd start

Abrir http://127.0.0.1:4321/ y usar el botón Instalar Fluye cuando el navegador lo ofrezca, o su menú de instalación. Ayuda: /instalar.html. La instalación requiere confirmación del navegador.

Desarrollo

npm run dev sigue funcionando. El service worker se registra únicamente en la compilación de producción para no interferir con el desarrollo. Es preferible usar otro puerto para dev si ya instalaste la PWA en el puerto 4321.

Alcance offline

Después de la primera visita con conexión, la PWA puede mostrar /offline.html y /instalar.html sin servidor. Las páginas financieras, respuestas de API y operaciones POST nunca se guardan en Cache Storage. Sin conexión no se inicia sesión ni se consulta ni registra información financiera.

Actualizaciones y versión final

Se conserva el identificador y alcance de instalación. En una nueva versión del service worker se debe cambiar el nombre de la caché y cerrar las ventanas existentes para activar la actualización. Solo se eliminan cachés con el prefijo fluye-pwa-public-. El guardado offline y la sincronización de movimientos quedan para una fase posterior.

Verificación manual

  1. En DevTools → Application, comprobar Manifest y Service Workers; recargar para confirmar control de la página.
  2. Instalar desde el navegador y comprobar el icono y la ventana independiente.
  3. En DevTools activar Offline y navegar a /dashboard: debe mostrarse la pantalla sin conexión sin exponer registros anteriores.
  4. Sin red, abrir /instalar.html: la ayuda debe seguir disponible.
  5. Volver a Online y reintentar, con servidor y MySQL encendidos.
  6. Comprobar que Cache Storage contiene exclusivamente los recursos públicos declarados en sw.js.

Para otros dispositivos se necesita un despliegue HTTPS. localhost pertenece al dispositivo que lo abre. Sin SMTP, la recuperación de contraseña devuelve 503 y no entrega tokens directamente. Para omitir importaciones de demostración durante una prueba pública, iniciar el servidor con FLUYE_SKIP_DEMO_IMPORT=1. El origen público debe configurarse mediante FLUYE_PUBLIC_ORIGIN antes de compilar y ejecutar.
